# Fortune Cookie Wisdom for Developers

A make.fun entry for the [Fortune Cookie Wisdom for Developers bounty](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44).
`main.py` writes one fortune-cookie line to `/output/entry.txt`:

> One day you will be the legacy code you curse — feared by strangers,
> understood by no one, not even by you.

Run it with `python3 main.py`.
